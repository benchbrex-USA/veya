The package is organized as a flat top-level module with one responsibility per file, plus an `experimental/` subpackage for pre-release features.

- Core runtime: `agent.py` exposes `Agent` (alias `RLAgent`) and the `load()` factory; it downloads checkpoints from Hugging Face (`huggingface_hub.snapshot_download`), loads `safetensors` weights, builds the model via `common.build_model`, applies optional calibration, and runs `system_one` — a single parallel forward over typed questions.
- Model & sequence layer: `common.py` defines `DecisionModel` (bidirectional encoder + type embedding + scorer + action head), `build_sequence` (CLS / question / [MASK] options / SEP / state / SEP layout), tokenization helpers, confidence scoring, and proper scoring rules used in training.
- Routing: `router.py` lazily loads up to three sibling checkpoints (`english`, `multilingual`, `typed-decisions`) behind an LRU cache protected by an RLock, selecting based on script detection (`lang.analyse`).
- High-cardinality choices: `shortlist.py` provides cosine-based shortlisting (`predict_shortlist`, `embed_fn_from_agent`); `release_bundle.py` wraps an Agent with a learned K=8 projection router (`ReleaseBundle`) that chooses between packed scoring and hierarchical shortlist routing, enforcing format/version checks against `shortlist_artifact.py` constants.
- Serving: `server.py` is stdlib-only (`http.server.BaseHTTPRequestHandler` + `ThreadingHTTPServer`) exposing `/health`, `/version`, `/v1/choice`, `/v1/noul`, `/v1/score`, `/v1/systemone`, `/v1/choice-hypothesis`, `/v1/choice-compare`; a process-wide `_INFER_LOCK` serializes all inference because the checkpoint is a single module and concurrent MPS calls are unsupported.
- Supporting layers: `calibration.py` (temperature scaling), `selective.py` (defer policy), `reranker.py`, `manifest.py` / `release_bundle.py` (signed release bundles), `email.py` / `presets.py` / `shortlist_artifact.py` / `lang.py` (domain utilities).
- Dependency direction is strictly inward: server → agent/router/bundle → common/lang/selective; experimental modules import from the stable core but not vice versa.
- Public surface is re-exported through `veya/__init__.py` (`__all__`), which also pins `__version__ = "0.3.5"`.
