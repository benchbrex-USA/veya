- Request and response validation is centralized in `contracts.py` using small typed helper functions (`_text`, `_state`, `_criteria`, `_probabilities`, `_number`, `_optional_text`) that raise `RequestError` or `UpstreamContractError` rather than returning booleans.
- Every error path in `Handler.do_POST` follows a uniform shape: set `status`/`error_code`, call `self.send(code, {"code": ..., "detail": ..., "request_id": ...})`, and log via `_safe_telemetry` in a `finally` block.
- External configuration is read from environment variables with explicit defaults (`VEYA_MODEL_URL`, `VEYA_WEB_PORT`, etc.) and validated at import time (e.g. `VEYA_PUBLIC_ORIGIN` scheme/host/path checks, non-loopback host requires a public origin).
- Static asset serving rejects path traversal by resolving the candidate path under `ROOT / 'static'` and requiring `is_relative_to(static_root)` plus an allowlist of allowed suffixes (`.css`, `.js`, `.mjs`, `.json`, `.png`, `.svg`).
- CSP and security headers are emitted uniformly through `headers_common()` which sets X-Content-Type-Options, Referrer-Policy, X-Frame-Options, Permissions-Policy, and Content-Security-Policy on every response.
