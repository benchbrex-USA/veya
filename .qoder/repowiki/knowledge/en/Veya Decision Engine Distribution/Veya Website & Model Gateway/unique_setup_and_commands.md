Run the full stack with `python3 -m web.model_server` (audited model on port 8080) and `python3 -m web.server` (website on port 3000). Configure via env vars: `VEYA_MODEL_URL`, `VEYA_MODEL_PORT`, `VEYA_WEB_PORT`, `VEYA_WEB_HOST`, `VEYA_PUBLIC_ORIGIN` (HTTPS-only origin required for public binding), `VEYA_ALLOWED_ORIGINS` (comma-separated), `VEYA_MODEL_TOKEN` (Bearer auth to upstream), `VEYA_DEVICE` (passed to release manifest loader).
