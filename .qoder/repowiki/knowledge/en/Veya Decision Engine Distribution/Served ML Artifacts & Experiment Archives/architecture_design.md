Two parallel artifact trees with distinct purposes:
- `models/production/` is the served model bundle. It contains the primary encoder (`model.safetensors`, `encoder/config.json`), tokenizer files (`tokenizer/tokenizer.json`, `tokenizer_config.json`), per-route calibration manifests (`calibration*.json` keyed by dataset split), a `choice_router.json` declaring the active routing strategy (`shortlist_k8_packed_rerank`, hierarchical K=8, packed max 19 candidates), an RL agent config (`rl_agent_config.json`) with temperature schedules per choice/score bucket, plus variant bundles under `multilingual/` and `typed-decisions/` that mirror the same structure for alternate encoder/tokenizer pairs.
- `artifacts/` is a read-only research archive organized by concern: `decisions/*.json` are human-authored decision records (status, evidence, revisit conditions) for each subsystem; `experiments/phaseN/` holds time-stamped experiment outputs, each rooted in a `graph.json` workflow DAG whose nodes track status (`complete`/`active`/`pending`/`not_applicable`) and cross-reference evidence files; `commercialization/` holds final commercialization audit outputs.
- Dependency direction is one-way: experiments produce artifacts, decisions reference artifacts, and `models/production/` is the leaf consumed by the serving runtime — nothing in this module imports code from elsewhere.
