- Data loaders return shuffled lists of `(text, label)` tuples seeded by a module-level `SEED = 17`, with fixed slice boundaries (e.g. `ag[:400]` cal vs `ag[400:800]` test, Banking indices `200:296`, `1100:1300`, `1300:1500`) separating calibration, training, and release sets.
- Packed-choice inference goes through `build_sequence` + `collate_items` + `agent.model(...)` wrapped in `torch.inference_mode()`, returning logits sliced to the number of criteria supplied.
- Shortlist retrieval trains a single `torch.nn.Linear(lv.shape[1], 128, bias=False)` projection over frozen encoder embeddings with Adam(lr=1e-3), CrossEntropyLoss, 6 epochs, batch size 32, and shuffles training order via `torch.randperm`.
- Cardinality-aware temperature fitting uses `veya.calibration.build_artifact` keyed by the bucket string returned from `temp_bucket(QTYPES['choice'], n)` (e.g. `choice:3-5`, `choice:11+`), and shipping is gated on explicit improvement checks comparing before/after accuracy/NLL/ECE.
- Reports are written as pretty-printed JSON files under `artifacts/experiments/phaseN/` with a trailing newline, and include seed, device, calibration version, and the raw metric dictionaries alongside any shipped artifact paths.
