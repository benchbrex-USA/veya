Four independent CLI entry points under `research/veyabench/`, each a self-contained experiment runner that loads the production agent via `veya.load(MODEL)` and writes JSON reports into `artifacts/experiments/phaseN/`. Dependency direction is one-way: phases 4 and 5 import shared helpers (`MODEL`, `ROOT`, `SEED`, `choice_logits`, `load_ag_news`, `load_banking`) from `run_phase3_eval.py`; phase 3 followup imports both the eval module and `veya.server.serve` to spin up an HTTP `/v1/choice` endpoint for an end-to-end smoke test. Each script follows the same pipeline shape — load data (AG News parquet or Banking77 CSV), build packed-choice logits through `veya.common.build_sequence` + `collate_items`, optionally train a frozen-encoder projection head (`torch.nn.Linear` over `embed_fn_from_agent` embeddings) with Adam/CrossEntropyLoss, fit a cardinality bucket temperature via `veya.calibration.build_artifact` / `fit_temperature`, and conditionally call `dump_calibration` / `save_route_calibration` when improvement thresholds are met. Evaluation metrics (accuracy, NLL, Brier, ECE, SAC/Wilson intervals) are computed in-process rather than delegated to a framework.
