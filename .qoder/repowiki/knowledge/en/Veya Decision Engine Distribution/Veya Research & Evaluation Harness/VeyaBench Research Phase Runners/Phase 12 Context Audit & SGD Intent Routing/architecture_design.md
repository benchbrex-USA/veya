Two-layer design: a small library (`phase12_sgd_inventory.py`, `phase12_context.py`) exposes immutable provenance and example construction, while each `run_phase12_*.py` is an independent CLI entry point that reads from shared artifacts under `artifacts/experiments/phase12/`. `phase12_sgd_inventory.py` is the root of provenance — it pins the SGD git commit, hashes every source file, splits services into train/validation/sealed by schema (no test dialogues are parsed), and writes `sgd_inventory.json`. `phase12_context.py` consumes that inventory to produce per-frame examples with three context modes (`utterance_only`, `previous_turn`, `full_context`) and a token-budget-aware `pack_context` that keeps the current USER turn plus as many whole prior turns as fit within `head_max_len`. The runner scripts depend only on these two modules plus `veya.common` / `veya.release_bundle`; they never import each other. Key runners: `run_phase12_context_baselines.py` scores a released Veya agent across all three modes; `freeze_phase12_context.py` compares the matched controls and writes a frozen `context_selection.json` declaring the chosen mode; `run_phase12_context_audit.py` computes exact-input feasibility ceilings and regression pairs; `run_phase12_sparse_scorer.py` trains a fixed-dimension linear scorer over lexical features as a research candidate; `run_phase12_g11_scorer.py`, `run_phase12_sgd_baseline.py`, `run_phase12_sparse_compare.py`, `run_phase12_candidate_access.py`, and `prepare_phase12_label_review.py` provide additional diagnostics and comparisons against the same inventory/schema contract.
