Two cooperating layers: shared protocol/scoring utilities plus per-phase runner scripts.

- `phase6_protocol.py` is the single source of truth for split boundaries (`SHORTLIST_TRAIN`, `RERANKER_TRAIN`, `CALIBRATION`, `RERANKER_VAL`, `RELEASE_TEST`, `LOCKED_TEST`) and immutable constants (`MAX_EPOCHS`, `LEARNING_RATE`, `BATCH_SIZE`, `HIGH_CONFIDENCE`). It exposes `assert_training_id` / `example_id` guards so gradient steps only touch the `train:800..8600` slice, plus statistical helpers `paired_bootstrap`, `promote`, `pair_relation`, `confusion_graph`, and `split_hash` used by every runner.
- `phase6_score.py` provides the batched scoring path `score_sets`, which builds `choice` sequences via `veya.common.build_sequence`, runs either the base agent or a `K8Reranker` through `_forward`, and returns logits/probabilities/margins. This is the only place that touches the model forward pass.
- Phase-6 runners are independent entry points under `research/veyabench/run_phase6_*.py`: `run_phase6_baseline.py` freezes the reranker and produces validation/test predictions plus confusion graphs; `run_phase6_train.py` fine-tunes a cloned `K8Reranker` head with listwise + optional pairwise loss; `run_phase6_interaction.py` and `run_phase6_final.py` consume the trained candidate artifacts. All read the frozen release manifest from `artifacts/release/manifest.json` and write results into `artifacts/experiments/phase6/`.
- Phase-7 runners in `run_phase7_adapt.py` and `run_phase7_update_audit.py` restore the phase-6 control weights before each experiment, then train only the last N encoder layers plus `final_norm`/`head`/`type_emb`/`scorer` via separate AdamW parameter groups. A promotion gate checks paired-bootstrap CI, high-confidence error rate, AG News, small-choice, and anchor preservation before writing `finalist.pt`.
- Dependency direction is one-way: runners import `phase6_protocol` and `phase6_score`; those two modules depend only on `veya.*` and `transformers`. Runners never import each other.
