One-way dependency chain across four sibling layers with no shared Python imports between them: `veyabench/` defines the held-out protocol, metrics, and phase-gated experiment scripts (`run_phase*.py`) that read static assets under `data/` (Banking77, SGD, CLINC150, MASSIVE, HWU64, ag_news) plus manifests in `configs/`; those experiments write evaluation outputs consumed by `scripts/` (Colab notebook generator, CPU sweep, latency benchmark, application workflow bench, plotting); final numbers are archived as JSON under `results/`. Cross-child wiring is filesystem-based — paths to `data/<dataset>/`, `configs/*.json`, and `results/*.json` are the only contract. The README documents the public entrypoint and the `USE_TF=0` environment variable required to avoid a TensorFlow/abseil deadlock on macOS Python 3.9; this branch is evidence-only and not imported by the production `veya` package.
